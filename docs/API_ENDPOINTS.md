# API Reference (Planned)

Base URL (local): `http://localhost:8000`
Interactive docs: `http://localhost:8000/docs` (auto-generated by FastAPI/Swagger)

| Method | Endpoint | Description | Owner |
|---|---|---|---|
| GET | `/health` | Liveness check | Backend |
| POST | `/auth/signup` | Register farmer/buyer/FPO (delegates to Supabase Auth) | Backend |
| POST | `/auth/login` | Login, returns JWT | Backend |
| GET | `/farmers/{id}` | Get farmer profile | Backend |
| POST | `/farmers` | Create farmer profile | Backend |
| GET | `/buyers` | List verified buyers (filter by crop/location/quantity) | Backend |
| POST | `/buyers` | Register a buyer | Backend |
| GET | `/prices/{crop}` | Latest mandi price + forecast for a crop/region | AI/ML |
| GET | `/prices/{crop}/history` | Historical price series (for charts) | AI/ML |
| POST | `/decision` | Given crop + location + quantity + storage → SELL/WAIT/STORE/AGGREGATE + confidence | AI/ML |
| POST | `/agent/query` | Agentic endpoint: raw farmer text/voice-transcript in → orchestrated, composed answer out | AI/ML |
| POST | `/voice/transcribe` | Audio in → BHASHINI ASR → text (+ detected language) | Backend |
| POST | `/voice/speak` | Text + language in → BHASHINI TTS → audio out | Backend |
| POST | `/transactions` | Create a transaction/offer between farmer and buyer | Backend |
| GET | `/transactions/{id}` | Transaction status & payment tracking | Backend |
| POST | `/logistics/route` | Given pickup + drop points → optimized route (OpenRouteService) | Backend |

> This file is a living contract between frontend and backend — update it whenever a
> route's request/response shape changes, and keep it in sync with the FastAPI
> `/docs` output.
