# API Reference

Base URL (local): `http://localhost:8000`
Interactive docs: `http://localhost:8000/docs` (auto-generated by FastAPI/Swagger)

Every request except `GET /health`, `GET /`, and the public reference-data endpoints
(`/prices/*`, `/logistics/warehouses`, `/quality/*`) requires a Firebase ID token:
`Authorization: Bearer <firebase-id-token>`. Endpoints marked **role** require the caller
to have finished registration as that role; others accept any authenticated role.

| Method | Endpoint | Description | Auth |
|---|---|---|---|
| GET | `/health` | Liveness check | none |
| GET | `/auth/me` | Resolve identity: role + linked profile (null role/profile before registration) | any signed-in user |
| POST | `/auth/register/farmer` | Complete registration as a Farmer, creates the Farmer profile | any signed-in user, unregistered |
| POST | `/auth/register/buyer` | Complete registration as a Buyer | any signed-in user, unregistered |
| POST | `/auth/register/fpo` | Complete registration as an FPO | any signed-in user, unregistered |
| GET | `/farmers/listings` | The logged-in farmer's own crop listings | FARMER |
| POST | `/farmers/listings` | Create a crop listing (appears in every buyer's Marketplace feed) | FARMER |
| GET | `/buyers/requirements` | List active buyer purchase requirements | any |
| POST | `/buyers/requirements` | Post a purchase requirement under the logged-in buyer | BUYER |
| GET | `/fpos` | List registered FPOs + pooling stats | any |
| GET | `/fpos/pools` | List FPO aggregation pools | any |
| POST | `/fpos/pools` | Create a pool under the logged-in FPO | FPO |
| POST | `/fpos/pools/{id}/add-member` | Add a registered farmer (by phone) to a pool | FPO, own pool |
| GET | `/fpos/pools/{id}/payout-ledger` | Transparent per-farmer payout breakdown | any |
| GET | `/marketplace/listings` | Unified feed: farmer lots + FPO pools | any |
| GET | `/marketplace/buyer-trust/{buyer_id}` | Buyer trust score computed from real transaction history | any |
| GET | `/marketplace/offers` | Offers relevant to the caller (buyer's own / farmer's own listings) | any |
| POST | `/marketplace/offers` | Submit a digital offer on a listing | BUYER |
| POST | `/marketplace/offers/{id}/counter` | Counter an offer's price/terms | any party |
| POST | `/marketplace/offers/{id}/accept` | Accept an offer on your own listing — creates the escrow Transaction | FARMER, own listing |
| GET | `/prices/{crop}` | Latest mandi price + short-horizon forecast | none |
| GET | `/prices/{crop}/history` | Historical price series (for charts) | none |
| GET | `/prices/{crop}/nearby-mandis` | Spatial price arbitrage across nearby mandis | none |
| GET | `/prices/{crop}/forecast-multi-horizon` | 3/7/15/30-day forecast with confidence bounds | none |
| POST | `/decision/recommend` | SELL/WAIT/STORE/AGGREGATE recommendation + confidence | any |
| POST | `/decision/compare-net-realization` | Rank buyer offers by net realization | any |
| POST | `/agent/query` | Agentic endpoint: raw farmer text/voice-transcript in → orchestrated answer out | any |
| POST | `/quality/analyze` | Produce quality grading from an image/sample | any |
| POST | `/quality/certificate` | Generate a verifiable e-Pramaan quality certificate | any |
| GET | `/logistics/warehouses` | Verified warehouse/cold-storage directory | none |
| POST | `/logistics/pledge-loan` | e-NWR pledge loan calculator | any |
| POST | `/logistics/calculate-transport` | Freight cost estimator | any |
| POST | `/logistics/evaluate-storage` | Sell-now vs. store-and-sell comparison | any |
| GET | `/transactions` | Transactions relevant to the caller (as farmer or buyer) | any |
| POST | `/transactions/{id}/advance-escrow` | Advance the 4-stage milestone escrow | party to the transaction |
| GET | `/transactions/{id}/invoice` | Digital invoice / escrow receipt | party to the transaction |
| GET | `/grievances` | Grievance tickets (own, or all for Admin) | any |
| GET | `/grievances/stats` | Dispute resolution stats | any |
| POST | `/grievances` | Raise a dispute against one of your own transactions | FARMER or BUYER |
| POST | `/grievances/{id}/resolve` | Resolve a grievance ticket | ADMIN |
| GET | `/admin/metrics` | Real aggregate platform KPIs (live queries, not fixtures) | ADMIN |
| GET | `/admin/disputes` | Open disputes across the platform | ADMIN |

> This file is a living contract between frontend and backend — update it whenever a
> route's request/response shape changes, and keep it in sync with the FastAPI
> `/docs` output.
